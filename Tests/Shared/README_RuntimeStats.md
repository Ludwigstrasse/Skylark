# Shared runtime stats options

These options are shared by `SkylarkCadEditorLab` and `SkylarkCadSceneTechniques`.

## Command line

- `--title-stats`
- `--no-title-stats`
- `--print-stats`
- `--no-print-stats`
- `--stats-interval=<seconds>`
- `--title-stats-every=<frames>`

## Environment

- `SKYLARK_TITLE_STATS`
- `SKYLARK_PRINT_STATS`
- `SKYLARK_STATS_INTERVAL`
- `SKYLARK_TITLE_STATS_INTERVAL_FRAMES`
