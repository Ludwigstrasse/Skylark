# Shared Sample Camera Options

Both `SkylarkCadEditorLab` and `SkylarkCadSceneTechniques` now accept a shared set of
camera/input tuning options.

## Command line

- `--orbit-scale=<float>`
- `--pan-scale=<float>`
- `--zoom-scale=<float>`
- `--invert-orbit-y`
- `--no-fit`
- `--no-print-controls`

## Environment variables

- `SKYLARK_ORBIT_SCALE`
- `SKYLARK_PAN_SCALE`
- `SKYLARK_ZOOM_SCALE`
- `SKYLARK_INVERT_ORBIT_Y`
- `SKYLARK_AUTO_FIT`
- `SKYLARK_PRINT_CONTROLS`
